# EduFund: Learn-to-Earn with Tokenized Scholarships
EduFund is a decentralized platform enabling transparent, milestone-based educational scholarships using STX tokens.

## 🔑 Key Features
- Student registration and profile management
- Scholarship creation with milestone-based fund release
- Verified mentor system for milestone validation
- Platform fee management
- Secure fund distribution

## 🛠️ Technical Implementation
- Smart contract written in Clarity
- Comprehensive test suite
- Security features including:
  - Access control
  - Input validation
  - Safe fund transfers
  - Owner-only administrative functions

## 🚀 Getting Started
1. Install Clarinet
2. Clone the repository
3. Run tests: `clarinet test`

## 💻 UI Components
- Student Dashboard
- Scholarship Creation Form
- Milestone Tracking Interface
- Mentor Verification Portal

## 🔒 Security
- Owner-only administrative functions
- Verified mentor system
- Safe fund management
- Input validation on all functions

Run the test suite:

clarinet test
